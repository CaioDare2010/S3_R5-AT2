## API Reference
### Produtos
### GET /Produtos
-**Descrição**: Obtem uma lista de produtos
-**Response**: Array do cliente

### POST /Produtos
-**Descrição**: Criar produto
-**Response**:
```
{
    "mensage": "Produto criado com sucesso!"
}
```

### Clientes
### GET /Clientes
-**Descrição**: Obtem uma lista de clientes
-**Response**: Array do cliente

### POST /Clientes
-**Descrição**: Cadastrar cliente
-**Response**: 
```
{
    "mensage": "Cliente cadastrado com sucesso!"
}
```
